# Customizing and Creating Drivers

This guide covers two scenarios: extending an existing built-in driver with additional rules, and creating a brand-new driver from scratch.

For an overview of what drivers are and which platforms are built in, see [Drivers](drivers.md).

---

## Customizing Existing Drivers

### Important: Frozen Rules

`HConfigDriverRules` and its sub-models (`ParsingRules`, `NegationRules`, `IdempotencyRules`, `SectionalRules`) are **frozen Pydantic models**. You cannot call `.append()` on rule tuples. Instead, build new tuples by concatenating and use `model_copy(update=...)` to produce updated instances.

The `driver.rules` attribute itself is a regular Python attribute and can be reassigned.

---

### Example 1: Subclassing the Driver

Create a new class that subclasses a built-in driver and overrides `_instantiate_rules` to add rules.

```python
from hier_config.models import (
    MatchRule,
    NegationDefaultWithRule,
    SectionalExitingRule,
    OrderingRule,
    PerLineSubRule,
    IdempotentCommandsRule,
)
from hier_config.platforms.cisco_ios.driver import HConfigDriverCiscoIOS
from hier_config.platforms.driver_base import HConfigDriverRules


class ExtendedHConfigDriverCiscoIOS(HConfigDriverCiscoIOS):
    @staticmethod
    def _instantiate_rules() -> HConfigDriverRules:
        # Start with the base rules
        base_rules = HConfigDriverCiscoIOS._instantiate_rules()

        # Extend negation rules (grouped under base_rules.negation)
        new_negation = base_rules.negation.model_copy(update={
            "negate_with": (*base_rules.negation.negate_with, NegationDefaultWithRule(
                match_rules=(MatchRule(startswith="ip route "),),
                use="no ip route",
            )),
        })

        # Extend sectional exiting rules (grouped under base_rules.sectional)
        new_sectional = base_rules.sectional.model_copy(update={
            "sectional_exiting": (*base_rules.sectional.sectional_exiting, SectionalExitingRule(
                match_rules=(
                    MatchRule(startswith="policy-map"),
                    MatchRule(startswith="class"),
                ),
                exit_text="exit",
            )),
        })

        # Extend parsing rules (grouped under base_rules.parsing)
        new_parsing = base_rules.parsing.model_copy(update={
            "per_line_sub": (*base_rules.parsing.per_line_sub, PerLineSubRule(
                search="^!.*Generated by system.*$", replace="",
            )),
        })

        # Extend idempotency rules (grouped under base_rules.idempotency)
        new_idempotency = base_rules.idempotency.model_copy(update={
            "idempotent_commands": (*base_rules.idempotency.idempotent_commands, IdempotentCommandsRule(
                match_rules=(
                    MatchRule(startswith="interface "),
                    MatchRule(startswith="speed "),
                ),
            )),
        })

        # Extend ordering (top-level field)
        new_ordering = (*base_rules.ordering, OrderingRule(
            match_rules=(
                MatchRule(startswith="access-list"),
                MatchRule(startswith="permit "),
            ),
            weight=50,
        ))

        return base_rules.model_copy(update={
            "negation": new_negation,
            "sectional": new_sectional,
            "parsing": new_parsing,
            "idempotency": new_idempotency,
            "ordering": new_ordering,
        })
```

#### Using the Subclassed Driver

```python
from hier_config import Platform

def get_extended_hconfig_driver(platform: Platform):
    if platform == Platform.CISCO_IOS:
        return ExtendedHConfigDriverCiscoIOS()
    raise ValueError(f"Unsupported platform: {platform}")

driver = get_extended_hconfig_driver(Platform.CISCO_IOS)
```

### Example 2: Dynamically Extending an Instantiated Driver

If subclassing is not feasible, replace the driver's `rules` attribute after instantiation.

```python
from hier_config import get_hconfig_driver, Platform
from hier_config.models import (
    MatchRule,
    NegationDefaultWithRule,
    SectionalExitingRule,
    OrderingRule,
    PerLineSubRule,
    IdempotentCommandsRule,
)

driver = get_hconfig_driver(Platform.CISCO_IOS)

# Build updated sub-models
new_negation = driver.rules.negation.model_copy(update={
    "negate_with": (*driver.rules.negation.negate_with, NegationDefaultWithRule(
        match_rules=(MatchRule(startswith="ip route "),),
        use="no ip route",
    )),
})

new_sectional = driver.rules.sectional.model_copy(update={
    "sectional_exiting": (*driver.rules.sectional.sectional_exiting, SectionalExitingRule(
        match_rules=(
            MatchRule(startswith="policy-map"),
            MatchRule(startswith="class"),
        ),
        exit_text="exit",
    )),
})

new_parsing = driver.rules.parsing.model_copy(update={
    "per_line_sub": (*driver.rules.parsing.per_line_sub, PerLineSubRule(
        search="^!.*Generated by system.*$", replace="",
    )),
})

new_idempotency = driver.rules.idempotency.model_copy(update={
    "idempotent_commands": (*driver.rules.idempotency.idempotent_commands, IdempotentCommandsRule(
        match_rules=(
            MatchRule(startswith="interface "),
            MatchRule(startswith="speed "),
        ),
    )),
})

new_ordering = (*driver.rules.ordering, OrderingRule(
    match_rules=(
        MatchRule(startswith="access-list"),
        MatchRule(startswith="permit "),
    ),
    weight=50,
))

# Replace the driver's rules
driver.rules = driver.rules.model_copy(update={
    "negation": new_negation,
    "sectional": new_sectional,
    "parsing": new_parsing,
    "idempotency": new_idempotency,
    "ordering": new_ordering,
})
```

**When to use each approach:**

- **Subclassing** — reusable, modular extensions encapsulated in a new class.
- **Dynamic modification** — quick one-off changes when the driver is instantiated by external code.

## Creating a Custom Driver

### Overview

Subclass `HConfigDriverBase` and implement `_instantiate_rules()` to return an `HConfigDriverRules` instance. Optionally override `negation_prefix`, `declaration_prefix`, or `config_preprocessor`.

### Step 1: Define the Driver

```python
from hier_config.platforms.driver_base import (
    HConfigDriverBase,
    HConfigDriverRules,
    IdempotencyRules,
    NegationRules,
    ParsingRules,
    SectionalRules,
)
from hier_config.models import (
    MatchRule,
    NegationDefaultWithRule,
    SectionalExitingRule,
    OrderingRule,
    PerLineSubRule,
    IdempotentCommandsRule,
)


class CustomHConfigDriver(HConfigDriverBase):
    """Custom driver for a specific operating system."""

    @staticmethod
    def _instantiate_rules() -> HConfigDriverRules:
        return HConfigDriverRules(
            negation=NegationRules(
                negate_with=(
                    NegationDefaultWithRule(
                        match_rules=(MatchRule(startswith="ip route "),),
                        use="no ip route",
                    ),
                ),
            ),
            sectional=SectionalRules(
                sectional_exiting=(
                    SectionalExitingRule(
                        match_rules=(
                            MatchRule(startswith="policy-map"),
                            MatchRule(startswith="class"),
                        ),
                        exit_text="exit",
                    ),
                ),
            ),
            ordering=(
                OrderingRule(
                    match_rules=(MatchRule(startswith="interface"),),
                    weight=10,
                ),
            ),
            parsing=ParsingRules(
                per_line_sub=(
                    PerLineSubRule(
                        search="^!.*Generated by system.*$",
                        replace="",
                    ),
                ),
            ),
            idempotency=IdempotencyRules(
                idempotent_commands=(
                    IdempotentCommandsRule(
                        match_rules=(MatchRule(startswith="interface"),),
                    ),
                ),
            ),
        )
```

### Step 2: Customize Prefixes (Optional)

```python
    @property
    def negation_prefix(self) -> str:
        return "disable "

    @property
    def declaration_prefix(self) -> str:
        return "enable "
```

### Step 3: Register and Use the Driver

Create a custom platform enum and a factory function:

```python
from enum import Enum, auto
from hier_config import get_hconfig_driver
from hier_config.platforms.driver_base import HConfigDriverBase

class CustomPlatform(str, Enum):
    CUSTOM_PLATFORM = auto()

def get_custom_hconfig_driver(platform) -> HConfigDriverBase:
    if platform == CustomPlatform.CUSTOM_PLATFORM:
        return CustomHConfigDriver()
    return get_hconfig_driver(platform)
```

Use it in a workflow:

```python
from hier_config import WorkflowRemediation, HConfig

driver = get_custom_hconfig_driver(CustomPlatform.CUSTOM_PLATFORM)
running = HConfig(driver)  # or load from text
intended = HConfig(driver)

workflow = WorkflowRemediation(running, intended)
print(workflow.remediation_config)
```

## Key Methods in HConfigDriverBase

| Method | Purpose |
|--------|---------|
| `idempotent_for(config, other_children)` | Find the idempotent match for a config node among other children |
| `negate_child(child)` | Negate a child using the three-step cascade: `negate_with` → `negation_default_when` → `swap_negation` |
| `negate_with(config)` | Return a fixed negation string if a `NegationDefaultWithRule` matches |
| `swap_negation(child)` | Toggle the negation prefix on a child's text |

| Property | Default | Purpose |
|----------|---------|---------|
| `negation_prefix` | `"no "` | String prepended to negate a command |
| `declaration_prefix` | `""` | String prepended to declare a command (e.g. `"set "` for JunOS) |
